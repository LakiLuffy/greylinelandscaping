# Reference Website Analysis: Supreme Green Style Target

This document records the features, layout, and design direction from the supplied reference website. Use it as the baseline when replacing the old Greyline Landscaping website. The goal is not to copy the brand, text, or assets directly, but to emulate the structure, confidence, and conversion flow for an updated landscaping website.

## Core Intent

- Position the company as a premium, professional landscaping partner for new home builds.
- Lead with strong outdoor project imagery and a clear promise.
- Build trust quickly through licenses, memberships, reviews, process clarity, and real project visuals.
- Move visitors toward a simple contact or lead form.
- Keep the experience visually direct, full-width, image-led, and low clutter.

## Page Structure To Emulate

1. Header and hero
   - Transparent or dark overlay header on top of a full-width hero.
   - Left-aligned logo, compact navigation, and phone/contact action.
   - Full-bleed background video or large hero image showing a finished high-end landscape.
   - Centered hero headline in white over the media.
   - Trust/accreditation badges overlapping the lower-left of the hero.

2. Intro value proposition
   - Solid olive-green band directly under the hero.
   - Short centered paragraph explaining the process and value.
   - Emphasis on one point of contact, fixed price, warranty, low maintenance, luxury, and security.
   - Secondary line inviting the visitor to discuss their project.
   - Burnt-orange primary CTA button such as "Connect" or "Get Started".
   - Large subtle background leaf or brand-mark watermark.

3. Portfolio gallery
   - White background with bold uppercase section title.
   - Six-image grid on desktop, typically 3 columns x 2 rows.
   - Square or near-square project photography.
   - Images should show complete outdoor outcomes: entrances, paving, gates, lighting, gardens, alfresco, fire pit, lawn, and modern home exteriors.
   - Mobile can become a horizontal carousel or stacked gallery.

4. License and membership trust strip
   - Narrow white section after the gallery.
   - Accreditation logo on each side with centered trust statement.
   - Message should connect licensing and outdoor completion capability.

5. Three-step process band
   - Full-width three-column visual section.
   - Columns: Consult, Design, Construct.
   - Each tile uses an image background with tinted overlay.
   - Short explanatory copy and a "Read more" style action.
   - Consult uses olive tones, Design uses gold/khaki tones, Construct uses burnt-orange tones.
   - The section should explain a clear end-to-end journey, not just list services.

6. Reviews and social proof
   - Centered heading: "What our customers are saying".
   - Circular rating badge with 4.9 or equivalent score.
   - Short line about review volume.
   - Grid of review cards from multiple platforms.
   - Each card includes platform logo, star rating, short quote excerpt, and read-more link.
   - Platforms in the reference include Google Reviews, Yellow Pages, True Local, ProductReview, Houzz, and hipages.

7. Instagram or project-feed section
   - Centered link-style heading.
   - Horizontal row or carousel of square social/project images.
   - Used as living proof that the business is active and project-focused.

8. Accreditation logo row
   - Clean row of four logos in bordered white boxes.
   - Reference categories: BPC/licensed builder, Master Builders, Landscaping Victoria, HIA.
   - For Greyline, replace with relevant real memberships, awards, or certifications only.

9. Lead magnet / ebook section
   - Full-width dark green photographic background.
   - Ebook/mockup image on the left.
   - Form on the right.
   - Heading asks a homeowner-focused question.
   - Offer a useful downloadable guide/checklist.
   - Fields: first name, surname, email, phone.
   - Consent checkbox, captcha or spam protection, submit button, short privacy disclaimer.

10. Footer
   - Olive-green footer with subtle brand-mark watermark.
   - Contact details: phone, email, address, showroom hours if relevant.
   - Social icons on the right.
   - Small copyright and design credit line at the bottom.

## Visual System

- Overall style: premium, practical, established, calm, and professional.
- Layout: full-width bands, centered content containers, image-led sections, minimal decoration.
- Color palette:
  - Olive green: `#5B6334`
  - Dark green: `#384327`
  - Muted gold/khaki: `#C6BF70`
  - Burnt orange CTA: `#9D5324`
  - White: `#FFFFFF`
  - Body text gray: `#555555`
- Typography:
  - Primary feel: clean sans-serif similar to Stevie Sans / Helvetica Neue.
  - Headings: bold, clean, uppercase where appropriate.
  - Hero H1 target: around 44-50px desktop, scaled down for mobile.
  - Body copy target: around 16-18px with generous line height.
- Components:
  - Buttons: rectangular, small radius around 3-4px, no shadow.
  - Primary buttons: burnt orange background, white text.
  - Secondary buttons/contact buttons: olive green background, white text.
  - Inputs: white background, compact height, small radius, simple border or no visible border.
  - Cards: simple white boxes with thin borders for reviews/accreditations.
- Imagery:
  - Use real landscape/project photography wherever possible.
  - Prioritize completed outdoor spaces over generic nature imagery.
  - Strong dusk/evening lighting, architectural lines, paving, gardens, walls, pools, gates, alfresco areas, and entry features.
  - Avoid decorative illustrations as primary visuals.

## Content Themes To Carry Over

- New home landscaping packages.
- One point of contact.
- Design through construction.
- Fixed-price or clear quoting process if accurate.
- Warranty or workmanship confidence if accurate.
- Luxury, security, low-maintenance outdoor living.
- Licensed, insured, accredited, and experienced team.
- Real customer reviews and visible social proof.
- Simple lead capture path.

## Functional Requirements For The Updated Site

- Responsive navigation with phone/contact CTA.
- Hero media support: video preferred if available; fallback image required.
- Portfolio grid with mobile-friendly behavior.
- Process section with three clickable steps.
- Reviews section with real review sources or curated testimonials.
- Social/project feed section; use static project images if live Instagram embed is not available.
- Lead form with validation, consent checkbox, spam protection, and privacy note.
- Accessibility basics:
  - Skip link or accessible navigation.
  - Meaningful alt text for images.
  - Keyboard-focusable links and buttons.
  - Sufficient contrast on image overlays.
  - Labels for all form fields.

## Rebuild Plan

1. Audit the current Greyline site files and identify which old sections should be removed.
2. Replace the old homepage structure with the reference-inspired sequence:
   hero, value proposition, portfolio, trust strip, process, reviews, social/project feed, accreditations, lead form, footer.
3. Define a Greyline-specific visual token set using the reference palette as inspiration, adjusted to Greyline branding if needed.
4. Source or prepare real project images and logo/accreditation assets.
5. Implement the homepage as a clean static page first.
6. Add responsive behavior for mobile navigation, portfolio, process tiles, and form layout.
7. Verify visually at desktop and mobile sizes before considering the redesign complete.

## Notes For Future Implementation

- Do not preserve the old website direction if it conflicts with this brief.
- The reference site is section-heavy but still simple; the updated site should feel rich through real imagery and trust proof, not through excessive effects.
- Keep CTAs direct and repeat them at key points.
- Use real Greyline claims only. If licenses, memberships, warranties, review counts, or ebook offers are not confirmed, use placeholders in code or omit until confirmed.
